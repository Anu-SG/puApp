# puApp
AL BOOK READER:
An AI-powered book-reading application designed to help people read, understand, and learn new vocabulary while reading PDF books.

ABOUT THE PROJECT:
Have you ever been reading a book and stopped because you didn't understand a word or know how to pronounce it?

AI BOOK READER aims to solve this problem by allowing users to upload pdf book, read them , and click on unfamilier words to learn more about them without interrupting their reading experience.
This project is being developed as a learning project to explore web development, Python, and AL integration.

PLANNED FEATURES:
1.Upload and read PDF books.
2.Click on any unfamiliar word while reading.
3.Get the meaning and definition of a selected word.
4.Learn the correct pronunciation of words.
5.Understand how a word is used in the current sentence.
6.Build vocabulary and improve reading skills.

#Features will be implemented gradually as development progresses.

TECHNOLOGIES:

1.Python--Backend programming.
2.Django--Web application framework.
3.HTML & CSS--Page structure and styling.
4.JavaScript --Interactive reading experience.
5.AI/Dictionary APPLs--Planned vocabulary explanations and contextual understanding.

DEVELOPMENT ROADMAP:

1.Set up the Django project.
2.Create the basic user interface.
3.Implement PDF upload functionality.
4.Display PDF books for reading.
5.Enable word selection.
6.Show word meanings and definitions.
7.Add pronunciation support.
8.Explain words based on their sentence context.
9.Text and improve the application.

PROJECT STATUS:
My goal is to build a simple and useful reading assistant that helps people improve  their vocabulary, pronunciation, and English comprehension while enjoying their favorite books.
